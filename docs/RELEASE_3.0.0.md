# 3.0.0 validation notes

Disco! 3.0.0 release validation record. The host checks below are complete; the listed hardware checks remain unverified.

## Prepared in this branch

- Visible `DISCO_VERSION` is 3.0.0. Internal `DISKOS_VERSION` stays 1.2.4 for the upstream update protocol. Installer and legacy app versions remain independent.
- Zune-first website with original-author acknowledgements, seven screens in four accents and Immersive 3.0 with transport controls open. The existing main-branch site supplies the layout, palette, galleries and native scroll chapters.
- Fresh actual LVGL host renders with synthetic demo artwork/history, generated by `tools/render-zune-site.py`.
- The theme source gate excludes third-party vendor headers, including libsmb2’s Xbox path with a space, so an ordinary clean build can run the gate without a local header-list override.
- Current release notes, theme guide, installation text, tour, acknowledgements and changelog. Complete firmware ZIP includes the Zune and Immersive guides.
- Rebuilt static MIPS32r2/o32/FP64/NaN2008 UI, versioned metadata and checksums. `tools/check-release.py` verifies source hash, visible version, payload hash/size and static MIPS ELF before packaging. The tag workflow also rejects a tag/version mismatch before building the Windows installer.

## Validation

See the payload build metadata for its source identity and exact binary checksums. Host UI checks cover Home focus/caption geometry, all main-icon gestures, the USB-C mode tile, modal volume touch protection, Immersive entry/exit and live transport rendering. USB output production-state-machine failure tests and storage lease/recovery tests are run separately. Website checks cover image/link integrity, accent/screen selection and enlarged screen viewing.

Host validation does not establish physical compatibility or battery life. The Windows installer/WSL environment is built by the existing tag workflow; it is not rebuilt locally as part of website previewing.

## Device acceptance before publishing

- [ ] Install/sign an SD update with the owner’s existing key; verify About shows Disco 3.0.0 and settings/music survive.
- [ ] Exercise Home/Now Playing focus, all three main-icon gestures, font choices, secondary confirmations and lock/wake on the round display.
- [ ] Test Immersive 3.0 transport, circular seeking/volume, early exit/reopen and Animations off while music plays.
- [ ] Test actual USB-C DAC enumeration, output card mapping, playback, timeout, unplug/retry and source/Bluetooth exclusion with supported cables. The guarded implementation’s card/PCM assumptions still need hardware acceptance.
- [ ] Long library Wall/Coverflow sessions; real playback/downloads together; Wi-Fi and Bluetooth reconnects; memory and battery observation.
- [ ] SMB3 transfers against a real NAS remain experimental until device tested.

To verify or reproduce the package, run `python3 tools/check-release.py --tag v3.0.0` and `python3 tools/package-release.py` from a clean checkout. No tag or release is created by these scripts.
