# Disco! 3.1.0

- Light / dark moves directly below the selected theme settings in Display. Dark, Light and Auto share one selector; Auto uses Dark from 19:00 to 07:00 and Light from 07:00 to 19:00 using the device clock. Changes apply while the screen is off. Outdoor mode keeps Light. Available only in themes supporting both appearances; Null retains its fixed appearance; Zune supports Dark, Light and Auto.
- Remove the separate Automatic Appearance menu entry and migrate its saved preference.
- Fixed top and bottom fades soften list boundaries in Disco, Squash and Null. Disco fades reuse its album-art backdrop.
- Zune Home menu uses medium-weight typography at the existing sizes.
- Duplicate volume reports no longer keep restarting idle power-off.
- Queue loading preserves the saved queue after read failures; saves check errors and sync durable replacements. Versioned queue storage preserves tabs and newlines in metadata and reads legacy files.
- Shutdown waits for queued and active listening-history work before the final sync, within the existing timeout.

- New Stats-inspired track actions sheet for Disco, Squash and Null, with shared headers, no Actions pill, and fixed edge fades plus a down chevron for more actions.

## Testing status

Prepared for user testing on stock FiiO V2.57. Physical installation, playback, charging, automatic appearance transitions and shutdown remain unverified for this release. Host builds and the 24-hour appearance schedule check passed. Queue/history fixes were committed without validation at the user's request.

The Stats-inspired track actions sheet is included for Disco, Squash and Null. Music uses Zune’s eleven-action order; Library long-press uses the same layout with the seven applicable selected-track actions in matching order. Enlarged submenu fonts remain a preview.

Use the existing owner signing keys for an SD update. Follow [Updating](../UPDATING.md); a version label alone does not prove which binary was installed.
