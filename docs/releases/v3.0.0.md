## Immersive 3.0

Zune joins the shared spinning-disc entry and exit animation. Vinyl, CD and Cover styles open into Immersive; tap the artwork to reveal the transport overlay with track/artist, elapsed time, previous, play/pause and next. Back remains available. The transition respects the Animations setting and handles early exit and reopening.

## Your controls, your collection

- A fixed four-square outline marks the Zune main shortcut, with its upper-right square in the current accent. Set independent **Main icon**, **Main icon double-tap** and **Main icon hold** actions under **Display → Music screen → Zune**.
- A minimal volume overlay follows the accent, with a thin rim, large number and quick fade. Its modal touch layer prevents accidental seeking through to Music; dragging keeps it open.
- Home and the bottom-edge Home gesture return to the main menu with Now Playing focused. Its larger caption has more room without changing the item spacing.
- Music gives the title/artist more room, shifts the cover partly beyond the edge, and groups bitrate/sample details below the duration.
- List, Wall and Coverflow album views follow the current theme. Library header pivots stay separate from row-selection gestures. Small/Medium/Large list fonts now select distinct sizes; the previous default is Medium.
- Six configurable Quick Settings actions, continuously scrolling visible track information and centred pause/resume feedback.
- Readable settings, battery information and secondary screens; separated SD-update confirmation text and buttons. Listening Stats, SongSphere and Tune labels no longer accidentally scroll vertically. Long selected folder titles scroll horizontally.

## USB-C output

A separate **usb-c out** mode uses a guarded pause → quiet check → host switch → stable USB playback device → sink rebind sequence. It resumes only the same track/session. Enumeration timeouts and unplug recovery return toward headphones, retaining recovery state when busy or blocked. USB DAC input remains a distinct mode.

**Device validation remains required:** real USB DAC/cable compatibility, output routing and unplug/retry behaviour have not been established by host tests. SMB3 also remains experimental pending real NAS testing. See the [release checklist](../RELEASE_3.0.0.md) for outstanding hardware checks.

## Website and updating

The refreshed website keeps Disco’s existing design and adds a Zune-first interactive walkthrough: Menu, Now Playing, Coverflow, Wall, Quick Settings, Listening Stats and **Immersive 3.0 with transport controls**, each in four accents. Images are real LVGL host renders with synthetic artwork/music fixtures.

Start from FiiO stock V2.57 for a first installation. Existing supported Disco installations can use a signed SD update; keep the same personal update key. Follow [updating](../UPDATING.md) or [first installation](../../RELEASE_INSTALL.md). Independent installer and legacy Disc Shelf version numbers are unchanged. The internal upstream update-protocol version remains 1.2.4; the visible Disco version is 3.0.0.
